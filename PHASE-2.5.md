# Phase 2.5 — Continuous Adaptive Frontier Search

Auto Coach is no longer a 10-question mission.

- Mission Mode remains 10 questions.
- Auto Coach runs at least 30 questions and can continue to 45 when the profile is still uncertain.
- Five clean, fast, hint-free correct answers can mark a skill provisionally secure and move forward rather than drill it.
- The controller explores adjacent skills, then follows the knowledge graph upward across grades until it finds the learner's challenge frontier.
- Grade is a school label, not an ability ceiling. Working frontier is stored by domain.
- Repeated difficulty still routes through confirmation, misconception detection, Learning Camp, and prerequisite recovery.
- Parent-grade identity is unchanged.
