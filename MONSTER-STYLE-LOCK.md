# Pahlawan Angka — Monster Master Set v1 (LOCKED)

The following monster concepts are approved and must stay in the same visual universe as Wira and Bunga:

1. Maharaja Nilai Tempat — bright blue / white / gold number golem, 100/10/1 motifs.
2. Jeneral Tambah-Tolak — red / white / gold operation warrior, + and − weapon motifs.
3. Bahbahgi — purple / gold math wizard with division / equal-part motifs.
4. Penguasa Jam Berdetik — blue / white / gold clockwork knight, clock / gears / hourglass motifs.

Approved generic minion addition:
- Pigiramid — pyramid / triangle stone golem with clear geometry motifs.

Production asset rules:
- Same anime/JRPG rendering family as Wira and Bunga.
- Full-body battle character.
- Transparent background.
- Faces left toward the hero.
- Static battle-ready stance is acceptable; do not bake projectile/attack FX into the idle asset.
- No card frame, scenery, logo, or UI baked into the image.
- Child-appropriate design.
- Clear mathematical motif readable at mobile battle scale.
- No sexualized/revealing character design.
- Do not use generic slime/goblin monster art for these four slots.
