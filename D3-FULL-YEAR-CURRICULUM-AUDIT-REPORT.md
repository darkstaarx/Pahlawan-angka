# Phase 3A-0 — Darjah 3 Full-Year Curriculum Canonicalization & Coverage Audit

**Target base:** `a9b36a520c0abf86db66c9d0d3f0c4c2ce8bb339`  
**Target release:** `3.43.0`  
**Scope:** curriculum identity + legacy coverage audit only.  
**Learner-visible rollout:** **NO expansion**. D3 Topic 7 remains the only QS v2 enabled / beta-LIVE topic.

## Why this phase exists

D3 Topic 7 is already production-quality QS v2. The remaining Darjah 3 curriculum registry still contains 44 standards with provisional competency IDs generated by slugification. Those IDs are not suitable as long-lived evidence keys, and the legacy question bank is far narrower than the KSSR registry.

This phase makes the remaining Year 3 curriculum stable enough to author question banks in batches without repeating the Topic 7 identity problem.

## Source basis

The shipped curriculum registry identifies its source as:

- `Dokumen Penjajaran KSSR (Semakan 2017) Edisi 3 Matematik Tahap I`
- Bahagian Pembangunan Kurikulum, Kementerian Pendidikan Malaysia
- Year 3 pages 40–62
- 50 declared / imported Year 3 standards

This phase does **not** invent new standards. It reviews the existing 50-record registry and stabilizes the `competencyId` identifiers for the 44 non-Topic-7 records.

## Legacy coverage audit

The current `questions/d3/core.js` contains one narrow generator branch for most legacy skills. It does not represent the breadth of the 44 non-T7 standards.

Audit result:

- **9 / 44** standards have some related legacy coverage, but need expansion or rewrite.
- **35 / 44** standards have no direct assessment of the registered standard.
- **0 / 44** are approved as-is for QS v2 authoring quality.

### Topic findings

| Topic | Legacy finding | Required authoring direction |
|---|---|---|
| T1 Nombor | Compare/place-value exist, but estimation, rounding and patterns are absent | Expand representation: number words, place value, estimation visuals, number lines, patterns |
| T2 Operasi | Basic arithmetic exists; KSSR word/mixed operations and 4-digit ×/÷ scope are not covered | Word problems, inverse/missing-value, error analysis, grouped/array models |
| T3 Pecahan/Perpuluhan/Peratus | Equivalent fraction + narrow decimal addition only | Heavy rewrite; fraction-area, hundred-grid, decimal place value, cross-representation tasks |
| T4 Wang | Only a simple “price/pay/change” question exists | Multi-step operations, ASEAN currency recognition, needs-vs-wants reasoning |
| T5 Masa | Current question mainly calculates finish time | Clocks/timetables, unit conversion, up-to-three-value operations, mixed operations, ×/÷ time |
| T6 Ukuran | Only a narrow cm→m question exists | Length/mass/liquid volume across all three operation families and unit relations |
| T8 Koordinat | No D3.POSITION handler in the legacy D3 bank | Build visual grid/map bank from scratch |
| T9 Data | Only bar-chart total exists | Collection/classification, pie chart reading, relation among pictograph/bar/pie |

## Important production defect exposed by the audit

`D3.POSITION` exists in the knowledge graph/curriculum mapping, but the current `questions/d3/core.js` has no `D3.POSITION` branch. Under the current dispatcher, a selected legacy skill with no question returns the generic `2 + 2` fallback.

This phase **documents** that problem but does not hot-patch legacy routing. The correct fix is to author D3.T8 in QS v2 and route it under the same evidence/fallback discipline used for Topic 7.

## Representation requirements for authoring

These are engineering requirements derived from the assessment meaning of the existing registry; they are not new curriculum standards.

- T1: place-value model, number line, sequence/pattern, estimation context.
- T2: symbolic + bar/relational + grouping/array + contextual word problem.
- T3: fraction area, hundred grid, number line/place-value, cross-representation match.
- T4: realistic money scenarios, ASEAN currency visual recognition, needs/wants classification.
- T5: analogue/digital clocks, timetable/timeline, unit relation.
- T6: ruler/length context, scale/mass context, liquid/container context.
- T8: grid/map visual is mandatory for meaningful evidence.
- T9: table/classification plus pictograph, bar chart and pie chart visuals.
