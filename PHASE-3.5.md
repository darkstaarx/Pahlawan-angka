# Phase 3.5 — Boss Trial + Local Audio Reliability

## Audio
- All battle/UI SFX remain bundled inside `assets/audio/`.
- Added preload/cache and first-user-gesture unlock for mobile browser playback reliability.
- No WebAudio oscillator/synth and no network audio dependency.

## Manual Mission Boss
- 9 normal topic questions.
- Boss then has 20 HP = 5 correct hits.
- Boss questions #1–4 remain within the selected school-grade topic.
- Boss question #5 is a deliberate +1-grade stretch probe where available.
- For current D2 missions this maps to an appropriate D3 skill in the same domain.
- A wrong +1-grade boss probe is ceiling/stretch evidence only: it does not trigger Learning Camp or Restu Parent and does not invalidate D2 mastery.
- If any boss answer is wrong, the fight can take more than five displayed questions because the boss still requires five correct hits to defeat.
