# Tahun 6 Space + Data Curriculum Lock — v3.23

## Core rule

Never use a legacy broad skill node to claim mastery of a different KSSR competency.

### Unit 6 — Ruang
Active mastery must distinguish:
- angles / regular polygons;
- circle parts / radius-based construction;
- application problems involving space.

`D6.AREA` is retired. Rectangle/cuboid work must not silently count as proof of these Year 6 Space competencies.

### Unit 8 — Pengurusan Data dan Kebolehjadian
Active mastery must distinguish:
- pie chart completion/interpretation using 45°, 90° and 180° sectors;
- qualitative probability with reasonable reasons;
- daily problems combining data/chance reasoning.

Numeric fractional probability is not a Year 6 mastery requirement in this product path. Do not restore `prob_fraction` as evidence for `D6.PROB`.

## Migration rule

Retired evidence may be archived for history/debugging, but must never be copied into new skill mastery/evidence counters.

## Visual rule

Where the curriculum construct is graphical, the question must contain a readable mathematical figure. Do not replace a pie chart, protractor, circle diagram or coordinate representation with text-only arithmetic simply to reduce implementation work.
