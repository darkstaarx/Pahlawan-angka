# Pahlawan Angka v3.21.0

## World Response to Learning

This release makes proven mathematics progress visibly change the RPG world. It is an additive presentation/progression layer and does not alter question generation, mastery formulas, adaptive routing, battle damage, Daily Quest selection, or parental time controls.

### Product rules
- World restoration is driven only by learning evidence. XP, coins, streaks and time-in-app cannot advance it.
- A skill counts as secure for world restoration only at mastery >=85, confidence >=70, evidence >=4, stability >=55, plus competency-integrity readiness where a contract exists.
- Chapter landmarks progress through dormant -> awakening -> restoring -> restored.
- Restoration milestones are monotonic: once genuinely proven, the world does not visually collapse after one later mistake. Learning mastery can still become fragile and be scheduled for review.
- Existing learners are migrated silently: their current proven world state becomes the baseline without replaying old celebrations.
- World celebrations are deferred to Hub/Mission screens so they do not compete with battle, boss or Cikgu Wajar teaching moments.

### Visible changes
- Hub environment follows the active curriculum chapter and restoration stage.
- Hub shows a compact World Response status card.
- Mission screen gains a connected World Map of chapter landmarks.
- Existing mission cards show each landmark restoration state.
- New learning evidence can queue a restrained world-change reveal when returning to Hub/Missions.
