# Phase 3.2 — Restu Parent Dummy Flow

- Parent Mode requires PIN (demo 2580).
- After two failed guided-learning cycles for the same origin skill, Restu Parent activates.
- Student is locked for a minimum of 5 minutes for self-study.
- After 5 minutes, student can continue.
- Parent can bypass the timer with Restu Key (demo RESTU5).
- Lock is persisted in localStorage/database object and re-enforced from Hub/Mission entry.
- Successful Learning Camp resets the failure counter for that skill.
- Dummy/local flow only; no backend auth yet.
