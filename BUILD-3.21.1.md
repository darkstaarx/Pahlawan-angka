# Pahlawan Angka v3.21.1

## DEV World Lab + Boss Typed Answer

Patch release on baseline `7edac7776bd11c6f929635ea9ecefb02631b267a`.

### Product changes
- World Response v3.21.0 remains implemented but is hidden from normal pupils while product value is evaluated.
- DEV Mode gains a World Response Lab with ON/OFF and non-destructive visual previews for stages 0–3.
- DEV preview never edits mastery, confidence, evidence, stability or competency proof.
- Normal mission bosses may ask typed/free-response answers for safe answer formats.
- Maximum typed questions per boss encounter: **2**.
- The second typed item cannot immediately follow the first.
- If suitable answer formats are scarce, the boss may have only 1 typed question, or none.
- Auto Coach bosses, Guardian Focus, DEV bank tests (unless Force Typed preview is enabled), and boss stretch probes keep normal answer choices.
- Safe typed formats in this patch: plain numeric, money values, and percentages. Fractions/time/coordinates/text formats fall back to A/B/C/D.

### Learning integrity
Typed response changes input mode only. It does not change question generation, mastery gain, evidence rules, frontier logic, Cikgu Wajar, Daily Quest selection, battle damage, rewards or parent time controls.
