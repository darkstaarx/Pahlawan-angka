# D4 pupil-language correction — v3.86.73

The added payment questions used an awkward sentence joining card insertion and PIN entry, unnecessary technical vocabulary, and contexts that did not always suit the payment action. These are authored questions, not quotations from MyUASA or the textbook. The previous implementation review checked correctness, curriculum boundaries and technical regressions; it did not adequately assess pupil-facing Malay.

This pass uses `nombor PIN`, `mesin pembayaran`, and `kaedah pembayaran`, splits actions into short sentences, and keeps distinguishing evidence for debit cards, topped-up e-wallets and internet banking. Pictograph drinks now use countable package labels; comparison wording and hints are clearer. Measurement questions explicitly name the total mass or volume.

Astra reviewed the stems, hints and labels specifically for Year 4 pupil comprehension. This is an editorial review, not a claim of verbatim textbook alignment. Existing numerical, choice-uniqueness, stage-selection and protected-content regressions are retained. No learning, mastery, Restu, visual-asset or curriculum-routing behavior is changed.
