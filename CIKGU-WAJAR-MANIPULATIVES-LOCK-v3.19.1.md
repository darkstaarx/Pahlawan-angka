## Product rule
Cikgu Wajar must make the mathematical relationship visible before asking the pupil to retry. The visual is a teaching model, not decoration.

## Locked pedagogy
- **Place value:** show hundreds / tens / ones as distinct quantities and connect them back to symbols.
- **Addition / subtraction:** regroup or remove concrete units before showing the abstract equation.
- **Multiplication:** show equal groups.
- **Operasi bahagi mesti dimodelkan sebagai agih kepada kumpulan sama banyak**, not slicing one arbitrary object into pieces. Cutting a whole is reserved for fraction meaning.
- **Fractions:** parts must be equal-sized; equivalent fractions preserve the same amount while partition count changes.
- **Decimals:** link tenths/hundredths to place value and fraction models.
- **Percent:** explicitly connect percentage to “daripada 100”.
- **Ratio:** both quantities change by the same factor when simplifying or scaling.
- **Money:** distinguish price, amount paid, and change/balance.
- **Time:** move through elapsed time; never teach invalid clock notation such as 2:75.
- **Measurement:** use the correct instrument model — ruler, scale, measuring vessel — and keep the unit attached to the reading.
- **Data:** read values before comparison or arithmetic.
- **Coordinates:** x first, then y.

## Interaction rule
The teaching sequence is:
1. **Lihat** — show one relationship.
2. **Cuba dengan model** — pupil performs one visual action.
3. **Semak faham** — one short conceptual choice.
4. Existing **Cuba / Guna checkpoints** remain the proof of independent learning.

A successful manipulation is not mastery evidence. v3.19.1 must not write mastery, confidence, evidence, frontier state, damage, rewards, or adaptive routing.

## Sensory rule
Cikgu Wajar teaching stays at **calm intensity**. No coins, confetti, combat shake, strong haptics, or mastery cinematics inside the manipulative step. Existing v3.19.0 sensory rules still govern the game.
