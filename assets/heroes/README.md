# Aset watak rasmi

Hanya satu reka bentuk untuk setiap watak: Wira, Bunga dan Sidma. Lihat manifest.json untuk lokasi base dan SHA-256 yang diluluskan.

- Wira: idle.webp, salinan tepat idle-loop-0-v1.webp yang dipilih pengguna.
- Bunga: idle.webp dan sumber idle.png, chibi merah jambu dengan but bunga.
- Sidma: idle.webp dan sumber idle.png, chibi hijau dengan tongkat sigma.

Pose baharu mesti menggunakan base rasmi watak berkenaan sebagai satu-satunya rujukan reka bentuk. Jangan gunakan artwork lama daripada sejarah Git sebagai rujukan.

Animasi Wira yang dikekalkan berada dalam wira/frames/ dan wira/finisher/. Folder wira-chibi, bunga-chibi, sidma-chibi dan switch-cards telah digabung atau dibuang.

Balingan perisai daripada base terdahulu telah ditarik. Pertempuran biasa menggunakan base rasmi dengan gerakan ringkas sehingga pose yang betul disediakan. Efek kuasa disimpan berasingan dalam assets/fx/.
