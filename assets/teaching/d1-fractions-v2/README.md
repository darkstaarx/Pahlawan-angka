# Aset Pecahan D1 v2

Enam ilustrasi asal dijana menggunakan built-in image_gen pada 4 Oktober 2026. Setiap fail PNG berlatar telus mengandungi dua versi objek: dibelah dua (kiri) dan dipotong empat (kanan).

Epal, kek, coklat, kertas, reben dan kad disimpan dalam projek. Imej digunakan semula melalui CSS sprite viewport; tidak ada SVG atau gambar baharu dijana untuk setiap soalan. Penanda pilihan dan input murid ialah lapisan berasingan daripada ilustrasi.

Prompt sebenar disimpan dalam `generation-prompts.json`. Fail asal generator kekal dalam direktori generated_images Codex. Sumber bank dan logik jawapan berada dalam `questions/d1/fractions-audit-v1.js`, `js/fraction-visuals-v2.js` dan `js/fraction-answers-v1.js`.
